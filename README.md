# לוח משמרות מחלקת טק | מידברן 2026

## מבנה הפרויקט

```
techshifts/
├── index.html      — מבנה ה-HTML, רכיבים, ולוגו מוטמע (base64)
├── style.css       — כל ה-CSS: עיצוב, צבעים, רספונסיביות
├── app.js          — כל הלוגיק: אנשים, משמרות, state, בנייה דינמית, גרסה אופליין
├── manifest.json   — הגדרות PWA (שם, אייקונים, צבעים) — מאפשר "הוספה למסך הבית"
├── sw.js           — Service Worker: שומר את האתר בקאש לשימוש מלא ללא אינטרנט
├── icons/          — אייקוני PWA בגדלים שונים (נוצרו מהלוגו הקיים)
└── README.md       — זה
```

## הרצה מקומית

לפיתוח/בדיקה: `python3 -m http.server` בתיקייה ואז לפתוח `http://localhost:8000`.
אפשר גם לפתוח את `index.html` ישירות בדפדפן (ללא שרת) — אבל אז מצב האופליין (PWA) לא יעבוד,
כי Service Worker דורש אתר מתארח (HTTPS) או `localhost`.

## מצב אופליין (למידברן, בלי קליטה)

יש שני שכבות הגנה למקרה שאין אינטרנט בפלאייה:

1. **PWA מלא** — אם האתר מתארח בכתובת אמיתית (HTTPS, למשל GitHub Pages), אפשר "להוסיף למסך הבית"
   בטלפון, וה-Service Worker (`sw.js`) ישמור את כל האתר בקאש כך שהוא ימשיך לעבוד גם בלי קליטה.
2. **גרסה אופליין להורדה** — כפתור "📲 גרסה אופליין" (בהדר, ולממונה/ת תמיד; לכולם ברגע שכל
   המשמרות מולאו ואושרו) מייצר קובץ HTML עצמאי עם הלוח הסופי, שאפשר לשמור ולפתוח בטלפון
   בלי צורך באפליקציה או באינטרנט בכלל.

## שינויים נפוצים

### הוספת אדם לרשימה
ב-`app.js`, מערך `PEOPLE`:
```js
{name:'שם מלא', phone:'05X-XXXXXXX', camp:'שם הקאמפ'},
```

### שינוי תאריכים
- **משמרות רגילות** — `REGULAR_DAYS` ב-`app.js`
- **הקמות** — `SETUP_DAYS` ב-`app.js`

### שינוי צבעים
ב-`style.css`, משתני `:root`:
```css
--gold: #DFA030;
--navy: #1A1A2E;
```
